# leetcode_questions

LeetCode solutions, one folder per problem (`<Problem_Name>/README.md` with the problem link and `Solution.txt` with the code).
Folders are created automatically by the LeetCode Automator browser extension when a solution is accepted.

## Current contents

The three folders at the moment (`Test_Upload_216`, `Test_Upload_643`, `Test_Upload_910`) are placeholder uploads
used to test the extension's GitHub integration; they contain a `print(...)` line, not real solutions, and can be deleted.
